ทำอะไรได้บ้าง

🎯

% ทางการ ไม่ใช่แค่ค่าเดา

Claude ดึงตรงจาก API เดียวกับคำสั่ง /usage · ChatGPT อ่านจากตัวเลขที่ Codex จดไว้เอง · Grok ปักหมุดจากหน้าเว็บครั้งเดียวแล้วนับถอยหลังให้

🖥️

วิดเจ็ตมุมจอ

ย่อเป็นแถบเล็กลอยมุมขวาล่าง เห็นวงแหวน % ทั้งสามเจ้าตลอดเวลา ปรับความจางได้ ลากวางตรงไหนก็จำไว้

🔔

เตือนก่อนโควตาหมด

"อีก 20 นาทีจะเต็มถ้าใช้อัตรานี้" — เตือนล่วงหน้าตามอัตราการใช้จริง พร้อมสรุปประจำวันทุกค่ำ

📊

ประวัติย้อนหลัง 90 วัน

กราฟรายวัน/รายชั่วโมง เก็บข้อมูลไว้เองไม่หายแม้ log ต้นทางถูกลบ พร้อมส่งออกรายงานรายเดือนเป็น HTML/PDF

💸

ประมาณค่าใช้จ่ายเป็นบาท

เห็นยอดสะสมเดือนนี้ของแต่ละเจ้า คิดเป็นเงินบาทโดยประมาณ ตารางราคาแก้เองได้

🌗

มาสคอตน่ารัก + สองธีม

ประกายดาว ต้นกล้า และยูเอฟโอ ที่หน้าตาเปลี่ยนตามโควตา ธีมมืด/สว่างตามระบบ Windows

ความเป็นส่วนตัวมาก่อน: แอปอ่านเฉพาะไฟล์ log จำนวน token ในเครื่องคุณ ไม่มี telemetry ไม่มี analytics ไม่ส่งข้อมูลไปที่ไหน — ฟีเจอร์ที่ต้องต่อเน็ต (ดึง % ทางการของ Claude และเช็คอัปเดต) เชื่อมต่อเฉพาะเซิร์ฟเวอร์ของ Anthropic/GitHub โดยตรง และปิดได้ทุกตัว

ติดตั้งใน 3 ขั้น

  1. ดาวน์โหลดตัวติดตั้งจากปุ่มด้านบน แล้วเปิดไฟล์ TokenGauge-Setup.exe
  2. เปิดแอป — การ์ดจะหาไฟล์ log ของ Claude Code / Codex CLI ในเครื่องให้อัตโนมัติ
  3. อยากได้ตัวเลขตรงกับเว็บเป๊ะ ๆ เปิดสวิตช์ "ดึง % ทางการ" ในหน้าตั้งค่า แค่นั้นจบ
