# TokenGauge — มาตรวัดโควตา AI สำหรับ Windows

แอปเดสก์ท็อปเฝ้าดูการใช้งาน **Claude Code / ChatGPT (Codex CLI) / Grok CLI** แบบเรียลไทม์
พร้อมหน้าปัดวัดระดับ ตัวนับถอยหลังรีเซ็ต กราฟ 24 ชั่วโมง และแจ้งเตือนเมื่อใกล้เต็ม

> **ปลอดภัยโดยการออกแบบ** — อ่านเฉพาะไฟล์ `.jsonl` ที่ CLI เขียนไว้ในเครื่องคุณเอง
> ไม่แตะไฟล์ token/credential ไม่ต้องกรอก API key และไม่ส่งข้อมูลออกนอกเครื่องแม้แต่ไบต์เดียว

---

## เริ่มใช้งานใน 3 ขั้น

**1. ติดตั้ง Node.js** (เวอร์ชัน 18 ขึ้นไป) จาก https://nodejs.org

**2. เปิด PowerShell ในโฟลเดอร์นี้แล้วสั่ง**

```powershell
npm install
npm start
```

**3. สร้างไฟล์ติดตั้ง .exe** (ได้ทั้งตัวติดตั้งและแบบพกพา อยู่ในโฟลเดอร์ `dist/`)

```powershell
npm run build
```

## แอปอ่านข้อมูลจากที่ไหน

| การ์ด | โฟลเดอร์เริ่มต้น | วิธีนับ |
|---|---|---|
| Claude | `C:\Users\<ชื่อ>\.claude\projects` | บวกสะสมทุกข้อความ |
| ChatGPT | `C:\Users\<ชื่อ>\.codex\sessions` | ยอดสะสมสูงสุดต่อ session |
| Grok | `C:\Users\<ชื่อ>\.grok` | บวกสะสมทุกข้อความ |

ถ้าเครื่องคุณเก็บไว้ที่อื่น เปิด **ตั้งค่า → เลือก…** แล้วชี้ path ใหม่ได้เลย
แอปจะเดินหาไฟล์ `.jsonl` ในโฟลเดอร์ย่อยทุกชั้นให้เอง

**หมายเหตุเรื่อง Grok:** ถ้าใช้ Grok ผ่านเว็บหรือแอปมือถืออย่างเดียว จะไม่มีไฟล์ log ในเครื่อง
การ์ดจะขึ้นสถานะ "ยังไม่พบโฟลเดอร์ log" ซึ่งเป็นเรื่องปกติ ต้องใช้ผ่าน CLI เท่านั้นจึงจะอ่านได้

## ลิมิตคำนวณยังไง

ผู้ให้บริการไม่ได้ประกาศตัวเลขลิมิตอย่างเป็นทางการ แอปจึงให้เลือก 3 แบบ

- **ตามแพลน** — ใช้ค่าประมาณที่ชุมชนใช้กัน (Pro 44k / Max 5x 88k / Max 20x 220k token ต่อบล็อก 5 ชั่วโมง)
- **อัตโนมัติ (P90)** — ดูจากบล็อกที่คุณใช้จริงย้อนหลัง แล้วเอาเปอร์เซ็นไทล์ที่ 90 เป็นลิมิต
  แม่นกว่าในระยะยาว แต่ต้องมีบล็อกที่จบแล้วอย่างน้อย 3 บล็อกก่อน
  ระหว่างนั้นจะขึ้นว่า "กำลังเรียนรู้พฤติกรรมการใช้"
- **ปรับเทียบกับ % จริง (แม่นที่สุด)** — เปิดหน้า usage ของผู้ให้บริการ
  (เช่น claude.ai → Settings → Usage) แล้วกรอก % ที่เห็นจริงในหน้าตั้งค่า
  แอปจะคำนวณลิมิตจริงย้อนกลับจาก token ที่นับได้ (`limit = tokens ÷ %`)
  ค่านี้ชนะทั้งสองแบบข้างบน การ์ดที่ปรับเทียบแล้วจะมีเครื่องหมาย ✓ บนป้ายแพลน
  ล้างค่าได้ในหน้าตั้งค่าเมื่อไหร่ก็ได้

คลิกที่ป้ายแพลนบนการ์ดเพื่อสลับแบบเร็ว ๆ ได้

**ChatGPT แสดง % ทางการอัตโนมัติ:** Codex CLI จดสถานะโควตาจริง (rate limits)
ลงไฟล์ session ของตัวเอง แอปอ่านค่านั้นจาก log ในเครื่องโดยตรง — ไม่ต้องต่อเน็ต
ไม่ต้องตั้งค่าอะไร ตัวเลขอัปเดตทุกครั้งที่ใช้ Codex และถ้าหน้าต่างโควตารีเซ็ตไปแล้ว
โดยไม่มีการใช้ใหม่ จะแสดง 0% ตามจริง

**Grok ใช้วิธีปักหมุด:** grok.com ไม่มีช่องทางดึงโควตาอัตโนมัติอย่างปลอดภัย
จึงมีระบบปักหมุดแทน — เปิด grok.com → Settings → Usage แล้วกรอก % กับเวลารีเซ็ต
ในหน้าตั้งค่าของแอป การ์ด Grok จะแสดงค่านั้นพร้อมนับถอยหลังจริง (ป้าย "ปักหมุด")
พอรอบรีเซ็ตผ่านไป แอปจะกลับไปใช้ค่าประมาณจนกว่าจะปักใหม่

**โหมดเรียลไทม์ (เฉพาะ Claude, opt-in):** เปิดสวิตช์ "ดึง % ทางการจาก claude.ai"
ในหน้าตั้งค่า แอปจะถาม % ทางการจาก API ของ Anthropic ทุกรอบรีเฟรช
การ์ดจะขึ้นป้าย **● สด** สีเขียว และตัวเลขจะตรงกับหน้า claude.ai เสมอ
ข้อแลกเปลี่ยน: แอปต้องอ่าน token ของ Claude Code ในเครื่อง และต่อเน็ตหา
Anthropic (ที่เดียวเท่านั้น) — จึงปิดเป็นค่าเริ่มต้น เปิด/ปิดได้ตลอดเวลา
ถ้าเน็ตหลุดหรือ token หมดอายุ แอปจะกลับไปใช้ค่าประมาณและขึ้นป้าย "ค่าประมาณ"

> เมื่อไม่เปิดโหมดเรียลไทม์ ตัวเลขทั้งหมดเป็น **ค่าประมาณจาก log ในเครื่อง** —
> มิเตอร์จริงของผู้ให้บริการคิดถ่วงน้ำหนักตามโมเดลและรวมการใช้งานจากทุกอุปกรณ์
> จึงไม่มีทางตรงกันเป๊ะ การปรับเทียบช่วยให้ใกล้เคียงที่สุดเท่าที่ทำได้แบบออฟไลน์

การนับ token ถ่วงน้ำหนัก cache read ไว้ที่ 0.1 เท่า (ปรับได้ใน `src/config.js`)
เพราะ token ที่อ่านจากแคชคิดค่าถูกกว่า token ปกติมาก

## ลูกเล่นที่มีให้

- **วิดเจ็ตมุมจอ** — ติ๊ก "ย่อเล็กมุมจอ" ในแถบล่าง แอปจะย่อเป็นแถบเล็ก
  เกาะมุมขวาล่างเหนือ taskbar ลอยบนสุดตลอด และจำสถานะไว้แม้ปิดเปิดแอปใหม่
  กลับสู่ขนาดปกติด้วยปุ่ม ▭ บนแถบหัว หรือเมนูคลิกขวาที่ไอคอน tray
- **มาสคอตประจำ AI** — ประกายดาวส้ม (Claude), ต้นกล้าเขียว (ChatGPT), ยูเอฟโอม่วง (Grok)
  ลอยตัว กะพริบตา และหน้าเปลี่ยนตามโควตา: ยิ้ม → กังวลที่ 70% → ร้องไห้ที่ 90%
- **หน้าปัดโค้ง** พร้อมขีดสเกล เปลี่ยนเป็นสีเหลืองที่ 70% และสีแดงที่ 90%
- **ไอคอนถาดระบบแสดงตัวเลข %** วาดใหม่ทุกครั้งที่รีเฟรช พร้อม overlay บนไอคอนแถบงาน
- **โหมดมินิ** ย่อเป็นแถบเล็กลอยอยู่บนสุด เหมาะกับการเปิดคู่ระหว่างเขียนโค้ด (ปุ่ม ▭ มุมขวาบน)
- **กราฟแท่ง 24 ชั่วโมง** ดูจังหวะการใช้งานของตัวเอง
- **คาดการณ์เวลาที่จะเต็ม** จากอัตราการใช้ในบล็อกปัจจุบัน
- **แจ้งเตือน Windows** เมื่อถึงเปอร์เซ็นต์ที่ตั้งไว้ (ครั้งเดียวต่อบล็อก ไม่รบกวนซ้ำ)
- **ส่งออก CSV** เอาไปทำกราฟต่อใน Excel ได้
- ปิดหน้าต่างแล้วแอปย่อลงถาดระบบ ไม่ดับ — คลิกไอคอนเพื่อเรียกกลับ

## โครงสร้างไฟล์

```
tokengauge/
├─ main.js              หน้าต่าง, ถาดระบบ, แจ้งเตือน, ตั้งเวลารีเฟรช
├─ preload.js           สะพานเชื่อมที่ปลอดภัยระหว่างระบบกับหน้าจอ
├─ src/config.js        ค่าตั้งต้น, path เริ่มต้น, ตารางลิมิตแต่ละแพลน
├─ src/usage.js         หัวใจของแอป — อ่าน .jsonl, จัดบล็อก 5 ชม., คำนวณ %
├─ renderer/index.html  โครงหน้าจอ
├─ renderer/styles.css  ธีมมืดแบบหน้าปัดเครื่องวัด
├─ renderer/app.js      วาดหน้าปัด, นับถอยหลัง, หน้าตั้งค่า, ไอคอนถาดระบบ
└─ demo.html            เปิดในเบราว์เซอร์เพื่อดูหน้าตาโดยไม่ต้องติดตั้งอะไร
```

## อยากเพิ่มผู้ให้บริการรายใหม่

เพิ่มบล็อกใน `DEFAULT_PROVIDERS` ที่ `src/config.js` ระบุ `roots` กับ `aggregation`
ตัวอ่านไฟล์เขียนแบบยืดหยุ่นไว้แล้ว — มันจะไล่หา key ที่หน้าตาเหมือน usage
(`input_tokens`, `prompt_tokens`, `output_tokens` ฯลฯ) ในทุกระดับของ JSON ให้เอง
ส่วนใหญ่จึงใช้ได้เลยโดยไม่ต้องแก้โค้ดอ่านไฟล์
