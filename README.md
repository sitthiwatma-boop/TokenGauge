# TokenGauge — มาตรวัดโควตา AI สำหรับ Windows

แอปเดสก์ท็อปเฝ้าดูการใช้งาน **Claude Code / ChatGPT (Codex CLI) / Gemini** แบบเรียลไทม์
พร้อมหน้าปัดวัดระดับ ตัวนับถอยหลังรีเซ็ต กราฟ 24 ชั่วโมง และแจ้งเตือนเมื่อใกล้เต็ม

> **ปลอดภัยโดยการออกแบบ** — อ่านเฉพาะไฟล์ `.jsonl` ที่ CLI เขียนไว้ในเครื่องคุณเอง
> ไม่แตะไฟล์ token/credential ไม่ต้องกรอก API key และไม่ส่งข้อมูลออกนอกเครื่องแม้แต่ไบต์เดียว

---

## เริ่มใช้งานใน 3 ขั้น

**1. ติดตั้ง Node.js** (เวอร์ชัน 18 ขึ้นไป) จาก https://nodejs.org

**2. เปิด PowerShell ในโฟลเดอร์นี้แล้วสั่ง**

```powershell
npm install
npm start
```

**3. สร้างไฟล์ติดตั้ง .exe** (ได้ทั้งตัวติดตั้งและแบบพกพา อยู่ในโฟลเดอร์ `dist/`)

```powershell
npm run build
```

## แอปอ่านข้อมูลจากที่ไหน

| การ์ด | โฟลเดอร์เริ่มต้น | วิธีนับ |
|---|---|---|
| Claude | `C:\Users\<ชื่อ>\.claude\projects` | บวกสะสมทุกข้อความ |
| ChatGPT | `C:\Users\<ชื่อ>\.codex\sessions` | ยอดสะสมสูงสุดต่อ session |
| Gemini | — (ไม่มี log ในเครื่อง) | % จากหน้า "ขีดจำกัดการใช้งาน" บน gemini.google.com |

ถ้าเครื่องคุณเก็บไว้ที่อื่น เปิด **ตั้งค่า → เลือก…** แล้วชี้ path ใหม่ได้เลย
แอปจะเดินหาไฟล์ `.jsonl` ในโฟลเดอร์ย่อยทุกชั้นให้เอง

**Gemini (opt-in):** Gemini ไม่ทิ้งข้อมูลการใช้ไว้ในเครื่องเลย และ Gemini CLI เลิกให้บัญชี
Google ส่วนตัวล็อกอินแล้ว การ์ด Gemini จึงอ่าน % จากหน้า **ขีดจำกัดการใช้งาน**
(gemini.google.com/usage) ทางเดียว — ได้ทั้ง "การใช้งานปัจจุบัน" และ "ขีดจำกัดรายสัปดาห์"
พร้อมเวลารีเซ็ต ตรงกับที่เห็นบนเว็บ (นับรวมการใช้บนเว็บและแอปมือถือด้วย)
วิธีเปิด: **ตั้งค่า → Gemini → เปิดสวิตช์ "โควตาสดจาก gemini.google.com" → กดล็อกอิน**
แล้วล็อกอิน Google ในหน้าต่างของแอปหนึ่งครั้ง จากนั้นแอปจะเปิดหน้านั้นในหน้าต่างที่ซ่อนไว้
ทุก 10 นาที อ่านเฉพาะตัวเลขบนหน้า (ไม่แตะ cookie ของ Chrome/Edge ไม่ส่งข้อมูลไปที่อื่น)
ถ้ายังไม่เปิด การ์ดจะบอกให้ไปเปิดในหน้าตั้งค่า

> **เลิกรองรับ Grok แล้ว** — การ์ด, การล็อกอิน grok.com และ session เว็บที่เคยล็อกอินไว้
> ในแอปจะถูกลบทิ้งอัตโนมัติตอนเปิดแอปครั้งแรกหลังอัปเดต

## ลิมิตคำนวณยังไง

ผู้ให้บริการไม่ได้ประกาศตัวเลขลิมิตอย่างเป็นทางการ แอปจึงให้เลือก 3 แบบ

- **ตามแพลน** — ใช้ค่าประมาณที่ชุมชนใช้กัน (Pro 44k / Max 5x 88k / Max 20x 220k token ต่อบล็อก 5 ชั่วโมง)
- **อัตโนมัติ (P90)** — ดูจากบล็อกที่คุณใช้จริงย้อนหลัง แล้วเอาเปอร์เซ็นไทล์ที่ 90 เป็นลิมิต
  แม่นกว่าในระยะยาว แต่ต้องมีบล็อกที่จบแล้วอย่างน้อย 3 บล็อกก่อน
  ระหว่างนั้นจะขึ้นว่า "กำลังเรียนรู้พฤติกรรมการใช้"
- **ปรับเทียบกับ % จริง (แม่นที่สุด)** — เปิดหน้า usage ของผู้ให้บริการ
  (เช่น claude.ai → Settings → Usage) แล้วกรอก % ที่เห็นจริงในหน้าตั้งค่า
  แอปจะคำนวณลิมิตจริงย้อนกลับจาก token ที่นับได้ (`limit = tokens ÷ %`)
  ค่านี้ชนะทั้งสองแบบข้างบน การ์ดที่ปรับเทียบแล้วจะมีเครื่องหมาย ✓ บนป้ายแพลน
  ล้างค่าได้ในหน้าตั้งค่าเมื่อไหร่ก็ได้

  ช่องนี้จะซ่อนไปเมื่อเปิดโหมดสด เพราะ % ทางการแม่นกว่าอยู่แล้ว และแอปเรียนรู้ลิมิตเองได้
  จากค่านั้น (ดูหัวข้อโหมดเรียลไทม์)

คลิกที่ป้ายแพลนบนการ์ดเพื่อสลับแบบเร็ว ๆ ได้

**ChatGPT แสดง % ทางการอัตโนมัติ (เมื่อใช้ Codex):** Codex CLI จดสถานะโควตาจริง
(rate limits) ลงไฟล์ session ของตัวเอง แอปอ่านค่านั้นจาก log ในเครื่องโดยตรง —
ไม่ต้องต่อเน็ต ตัวเลขอัปเดตทุกครั้งที่ใช้ Codex

> **หมายเหตุ v1.2.8:** ยอด token ของ ChatGPT เคยต่ำกว่าความจริงมาก เพราะอ่านผิดฟิลด์
> (หยิบยอดของเทิร์นล่าสุดแทนยอดสะสมของ session) วัดจาก log จริงในเครื่องแล้วต่างกัน
> ราว 170 เท่า แก้แล้วในเวอร์ชันนี้ — ตัวเลขและค่าใช้จ่ายโดยประมาณของการ์ด ChatGPT
> จะกระโดดขึ้นมากหลังอัปเดต ซึ่งเป็นค่าที่ถูกต้อง ไม่ใช่ความผิดพลาด

ข้อควรรู้: โควตานี้**แชร์กับเครื่องมือฝั่งเว็บ** (Work, Workspace Agents, ChatGPT for
Excel) ซึ่งกินโควตาได้โดยไม่ทิ้งร่องรอยในเครื่อง ดังนั้นถ้าข้อมูลใน log หมดอายุแล้ว
แอปจะ**ไม่เดา** แต่ถอยไปใช้ค่าประมาณ/ค่าปักหมุดแทน — ถ้าใช้งานฝั่งเว็บเป็นหลัก
ให้ใช้ *โควตาสดจากเว็บ* หรือปักหมุด % ตามวิธีด้านล่าง

**ChatGPT ฝั่งเว็บ มี 2 วิธี:**

1. *โควตาสดจากเว็บ (ทดลอง, opt-in)* — เปิดสวิตช์ "โควตาสดจาก chatgpt.com"
   ในหน้าตั้งค่า แล้วกดปุ่มล็อกอิน **ในหน้าต่างของแอปเอง** หนึ่งครั้งด้วยบัญชีเดียวกับที่ใช้
   บนเว็บ (session อยู่ในแอปเท่านั้น ไม่แตะเบราว์เซอร์หรือ cookie อื่นใด) จากนั้นเปิดหน้า
   usage ในหน้าต่างนั้นหนึ่งครั้งให้แอปเรียนรู้วิธีถามข้อมูล แล้วกด "ทดสอบ" ดูผล
   การ์ดจะขึ้นป้าย **● สด** และแสดง % ตรงกับเว็บ
   endpoint ฝั่งนี้ไม่ทางการ ถ้าใช้ไม่ได้แอปจะถอยไปวิธีที่ 2 อัตโนมัติ

2. *ปักหมุดด้วยมือ* — เปิดหน้า usage ของ chatgpt.com แล้วกรอก % กับเวลารีเซ็ต
   ในหน้าตั้งค่าของแอป การ์ดจะแสดงค่านั้นพร้อมนับถอยหลังจริง (ป้าย "ปักหมุด")
   พอรอบรีเซ็ตผ่านไป แอปจะกลับไปใช้ค่าประมาณจนกว่าจะปักใหม่

**โหมดเรียลไทม์ (เฉพาะ Claude, opt-in):** เปิดสวิตช์ "ดึง % ทางการจาก claude.ai"
ในหน้าตั้งค่า แอปจะถาม % ทางการจาก API ของ Anthropic ทุกรอบรีเฟรช
การ์ดจะขึ้นป้าย **● สด** สีเขียว และตัวเลขจะตรงกับหน้า claude.ai เสมอ
ข้อแลกเปลี่ยน: แอปต้องอ่าน token ของ Claude Code ในเครื่อง และต่อเน็ตหา
Anthropic (ที่เดียวเท่านั้น) — จึงปิดเป็นค่าเริ่มต้น เปิด/ปิดได้ตลอดเวลา
ถ้าเน็ตหลุดหรือ token หมดอายุ แอปจะกลับไปใช้ค่าประมาณและขึ้นป้าย "ค่าประมาณ"

**ป้าย "สดล่าสุด HH:MM"** — ระหว่างที่ดึงค่าสดไม่ได้ แต่รอบเดิมยังไม่รีเซ็ต แอปจะคง
% ทางการที่วัดได้ครั้งล่าสุดไว้แทนการดิ่งไปค่าประมาณ (ในรอบเดียวกัน % มีแต่เพิ่ม ไม่มีลด
ค่านั้นจึงยังเป็นอย่างต่ำที่เชื่อได้) สำคัญมากถ้าคุณใช้โควตาจากฝั่งเว็บด้วย เพราะการใช้งาน
บนเว็บไม่ทิ้ง log ในเครื่องเลย ค่าประมาณจึงอาจเหลือ 0% ทั้งที่ของจริงใช้ไปแล้วเกือบ 30%
พอดึงค่าสดได้อีกครั้ง ป้ายจะกลับเป็น ● สด เอง

หมายเหตุ: token ของ Claude Code ถูกต่ออายุตอนคุณ**ใช้ CLI** ถ้าไม่ได้ใช้หลายชั่วโมง
มันจะหมดอายุแล้วโหมดสดล้มชั่วคราว — ใช้ Claude Code สักครั้งแล้วค่าจะกลับมาสดเอง
หรือเปิดสวิตช์ **"โควตาสดจาก claude.ai"** เพิ่มไว้เป็นทางสำรอง (ล็อกอินในหน้าต่างของแอป
เหมือน ChatGPT) แล้วแอปจะดึง % จากเว็บให้เองเมื่อ token หมดอายุ — เหมาะกับคนที่
ใช้ claude.ai บนเว็บเป็นหลัก เพราะโควตาที่ใช้จากเว็บไม่ทิ้ง log ในเครื่องเลย

คำตอบจาก API บอก **เวลารีเซ็ตจริง** ของทั้งรอบ 5 ชั่วโมงและรอบสัปดาห์มาด้วย
แอปจึงย้อนกลับไปนับ token ในเครื่อง**ในกรอบเวลาเดียวกับผู้ให้บริการ** ไม่ใช่กรอบที่ตัดเอง
ถ้าไม่ทำแบบนี้ ตัวเลข token กับ % จะเป็นคนละหน้าต่างกัน — เคยทำให้รายสัปดาห์ขึ้นแดง 97%
ทั้งที่รอบเพิ่งรีเซ็ตไปเมื่อเช้าและของจริงคือ 3%

เมื่อกรอบตรงกันแล้ว แอปจะ**เรียนรู้ลิมิตจริงเก็บไว้เอง** (`liveLimit` ใน config)
ไว้ใช้ตอน API ล่ม ซึ่งใกล้ความจริงกว่าค่าประมาณตามแพลนมาก ค่าที่เรียนรู้มีอายุ 14 วัน
และจะถูกล้างทันทีถ้าคุณเลือกแพลนเองในหน้าตั้งค่า (ตัวเลือกของคุณต้องมีผลเสมอ)

เปิดพร้อม Windows แล้วเจอป้าย "ค่าประมาณ" ตอนเข้าเครื่องใหม่ ๆ เป็นเรื่องปกติ —
แอปขึ้นมาก่อนที่ token ของ CLI จะถูกต่ออายุ ยิงครั้งแรกเลยไม่ผ่าน แอปจะลองใหม่เองใน
20 วินาที (แล้ว 45 และ 90) ไม่ต้องรอครบรอบรีเฟรช

> เมื่อไม่เปิดโหมดเรียลไทม์ ตัวเลขทั้งหมดเป็น **ค่าประมาณจาก log ในเครื่อง** —
> มิเตอร์จริงของผู้ให้บริการคิดถ่วงน้ำหนักตามโมเดลและรวมการใช้งานจากทุกอุปกรณ์
> จึงไม่มีทางตรงกันเป๊ะ การปรับเทียบช่วยให้ใกล้เคียงที่สุดเท่าที่ทำได้แบบออฟไลน์

การนับ token ถ่วงน้ำหนัก cache read ไว้ที่ 0.1 เท่า (ปรับได้ใน `src/config.js`)
เพราะ token ที่อ่านจากแคชคิดค่าถูกกว่า token ปกติมาก

## ลูกเล่นที่มีให้

- **แท็บประวัติ** — กราฟแท่งซ้อนแยกสีตามผู้ให้บริการ ดูรายวันย้อนหลัง 30 วัน
  หรือรายชั่วโมง 48 ชม. วาดด้วย SVG ล้วน ข้อมูลจาก history.json ที่แอปเก็บเอง
  (ย้อนหลังสูงสุด 90 วัน อยู่ครบแม้ log ต้นทางถูกลบ)
- **วิดเจ็ตมุมจอ** — ติ๊ก "ย่อเล็กมุมจอ" ในแถบล่าง แอปจะย่อเป็นแถบเล็ก
  เกาะมุมขวาล่างเหนือ taskbar ลอยบนสุดตลอด และจำสถานะไว้แม้ปิดเปิดแอปใหม่
  กลับสู่ขนาดปกติด้วยปุ่ม ▭ บนแถบหัว หรือเมนูคลิกขวาที่ไอคอน tray
- **ธีมสว่าง/มืด** — ตามระบบ Windows โดยอัตโนมัติ หรือเลือกเองในหน้าตั้งค่า
- **ค่าใช้จ่ายโดยประมาณ (บาท)** — ยอดสะสมเดือนนี้ใต้การ์ดแต่ละใบ
  ตารางราคาแก้ได้ที่ `pricing` ใน config.json (เป็นค่าประมาณ ไม่ใช่ยอดเรียกเก็บจริง)
- **รายงานรายเดือน** — ปุ่ม "รายงานเดือนนี้" ส่งออก HTML หน้าเดียว
  มีกราฟ+ตาราง เปิดในเบราว์เซอร์และพิมพ์เป็น PDF ได้
- **มาสคอตประจำ AI** — ประกายดาวส้ม (Claude), ต้นกล้าเขียว (ChatGPT), หยดน้ำฟ้า (Gemini)
  ลอยตัว กะพริบตา และหน้าเปลี่ยนตามโควตา: ยิ้ม → กังวลที่ 70% → ร้องไห้ที่ 90%
- **หน้าปัดโค้ง** พร้อมขีดสเกล เปลี่ยนเป็นสีเหลืองที่ 70% และสีแดงที่ 90%
- **ไอคอนถาดระบบแสดงตัวเลข %** วาดใหม่ทุกครั้งที่รีเฟรช พร้อม overlay บนไอคอนแถบงาน
- **โหมดมินิ** ย่อเป็นแถบเล็กลอยอยู่บนสุด เหมาะกับการเปิดคู่ระหว่างเขียนโค้ด (ปุ่ม ▭ มุมขวาบน)
- **กราฟแท่ง 24 ชั่วโมง** ดูจังหวะการใช้งานของตัวเอง
- **คาดการณ์เวลาที่จะเต็ม** จากอัตราการใช้ในบล็อกปัจจุบัน
- **แจ้งเตือน Windows** เมื่อถึงเปอร์เซ็นต์ที่ตั้งไว้ (ครั้งเดียวต่อบล็อก ไม่รบกวนซ้ำ)
- **ส่งออก CSV** เอาไปทำกราฟต่อใน Excel ได้
- ปิดหน้าต่างแล้วแอปย่อลงถาดระบบ ไม่ดับ — คลิกไอคอนเพื่อเรียกกลับ

```
├─ src/config.js        ค่าตั้งต้น, path เริ่มต้น, ตารางลิมิตแต่ละแพลน
├─ src/usage.js         หัวใจของแอป — อ่าน .jsonl, จัดบล็อก 5 ชม., คำนวณ %
├─ renderer/index.html  โครงหน้าจอ
├─ renderer/styles.css  ธีมมืดแบบหน้าปัดเครื่องวัด
├─ renderer/app.js      วาดหน้าปัด, นับถอยหลัง, หน้าตั้งค่า, ไอคอนถาดระบบ
└─ demo.html            เปิดในเบราว์เซอร์เพื่อดูหน้าตาโดยไม่ต้องติดตั้งอะไร
```

## อยากเพิ่มผู้ให้บริการรายใหม่

เพิ่มบล็อกใน `DEFAULT_PROVIDERS` ที่ `src/config.js` ระบุ `roots` กับ `aggregation`
ตัวอ่านไฟล์เขียนแบบยืดหยุ่นไว้แล้ว — มันจะไล่หา key ที่หน้าตาเหมือน usage
(`input_tokens`, `prompt_tokens`, `output_tokens` ฯลฯ) ในทุกระดับของ JSON ให้เอง
ส่วนใหญ่จึงใช้ได้เลยโดยไม่ต้องแก้โค้ดอ่านไฟล์
